Day 4 – Lists and Advanced String Practice

Overview
This folder contains practice problems combining list manipulation and more advanced string tasks. Many solutions include step-by-step prints to trace how the logic works.

Concepts Covered
- Iterating lists with indexes (enumerate) and manual accumulation
- Finding min/max and second largest using comparisons
- Removing duplicates while preserving order
- Implementing selection sort (without using sort())
- Reversing a list in-place using two pointers
- Flattening a nested list using nested loops
- List comprehension (squares 1–10)
- Dictionary-based frequency counting for characters
- String normalization (lowercasing and removing spaces)
- Using sorted() for anagram checks
- Splitting and joining sentences

Code Highlights
- List problems:
  - Sum and average of a 10-number list (manual running total)
  - Largest and smallest element tracking
  - Duplicate removal using a “unique list” approach
  - Selection sort implementation with visible swaps
  - Reverse list by swapping left/right indexes
  - Second largest detection while handling duplicates
  - Flatten nested list into a single list
  - Squares using list comprehension
- String problems:
  - Character frequency using a dictionary (including spaces)
  - Removing vowels by filtering characters
  - Palindrome check after normalization
  - Anagram check by sorting characters
  - First non-repeated character using a frequency pass + scan
  - Reverse each word in a sentence
  - Find the longest word in a sentence

Learning Outcome
I practiced classic data-structure tasks that show up often in interviews and scripting work. The “trace prints” helped me understand each loop and update step clearly.
